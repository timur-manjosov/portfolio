Tools I actually use. I leave out server infrastructure details on purpose.

## Working environment

- **Machine:** a ThinkPad running Arch Linux
- **Editor:** Neovim
- **Everyday:** terminal, Git, Docker for my own services

## Languages

Python, Java, Rust, C, Kotlin and Go. How well I know each one is on the
[About](/en/about/#what-i-work-with) page.

## This site

- Built with [Astro](https://astro.build/) as a fully static site, with no
  JavaScript framework in the browser.
- Maths is rendered to MathML at build time, with no script in the browser.
- Served by [Caddy](https://caddyserver.com/) on my own server.
- No cookies, no trackers, no third-party fonts or scripts.
- The [source code](https://github.com/timur-manjosov/portfolio) is public.
